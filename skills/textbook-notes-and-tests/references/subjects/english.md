# 英语专项

与通用规则及学段页面设计共同使用。根据教材主题组织语言运用，不把笔记做成脱离语境的单词翻译表。

## 课堂笔记

按需要选用“主题情境 → 核心词汇/搭配 → 句型对话 → 规律与易错点 → 简短迁移”。小学用具体场景和短对话帮助理解，单词与图中对象就近对应；中文解释简短明确。初高中可突出语篇结构、搭配、语法条件和例句比较，配图以解释情境或结构为主。

词汇保留本课词义、词性或搭配所需的信息；可数性、单复数、时态、人称和介词不能在例句中互相矛盾。语法说明配正确例句，避免把常见规律说成无例外规则。自编句子符合学生词汇水平，标清与课文原句的区别。

自然拼读按本课字母组合的实际发音归组，不能仅因词里有某个字母就归入同一读音。音标仅在教材或任务需要且能核实时使用；不以中文谐音替代发音教学。

## 图示、测评与核验

对话气泡归属清楚，人物动作和指代一致；价格、物品数量和币种须与问答对应。时间线或语法对比图服务于具体用法，不能以简化图示消除必要条件。

依目标选择词汇运用、情境对话、阅读、语言结构或写作题型；题干和必要材料完整，选择题干扰项不能形成多个同样成立的答案。写作留足对应词数的行数，评分允许合理表达。

无实际音频或明确配套朗读安排时，不生成依赖听力才能作答的题，也不推测教材听力答案。可改为阅读/情境练习并明确题型；用户要求听力时需落实音频或教师朗读稿及其使用方式。

逐字检查大小写、拼写、撇号、标点、词间距及连字符，检查句法、单复数与图文数量。手写字体不使用影响辨认的连笔，尤其区分易混字母。英语专项不自动用于其他外语，其他语言回退通用规则。
