# 数学专项

与通用规则及学段页面设计共同使用。数学配图用于解释数量、变化和空间关系；可以使用多幅分步图，但不以图多为目标。

## 课堂笔记的组织

按内容选择“情境/问题 → 概念及条件 → 图形或数量模型 → 推理/计算步骤 → 例题与检验”。区分定义、已知条件、推导结论和经验方法；公式写清变量、单位与适用条件。小学可用实物分组、数轴、条形图、面积分割理解运算；初高中侧重符号与图形互相对应，不省去关键推导。

同一例题中，图中的点名、数值、字母与每一步运算保持一致。辅助图靠近对应步骤；复杂构造按“原图 → 添加辅助线 → 得到关系”分图展示，避免把所有线挤在一张图上。

## 图示设计与核验

先在内容底稿中确定可核验的图示规格，再写入生图提示词。必要时用计算核验坐标、交点、长度或数值；计算用于核验，不替代笔记/学生卷整页 imagegen 路线。

| 图示 | 必须明确的规格与检查 |
| --- | --- |
| 数轴、分数、面积模型 | 原点、正方向、等距刻度；整体单位一致，等分确实等大；分子计数与涂色数量对应 |
| 坐标轴与函数图 | 轴名、原点、正方向、各轴刻度及单位；点坐标、截距、定义范围、端点开闭、趋势与表达式相符；横纵轴比例不同时明确标示，不从外观判断斜率或角度 |
| 平面几何 | 点在线上/内部/外部的位置，线段与延长线，平行、垂直、相等、角与弧的标记；不能凭看起来相等或垂直就添加题设未给的性质 |
| 辅助线 | 起止点、构造动作、线型及作用；例如“过 A 作 BC 的垂线，垂足为 D”，核对 D 的实际位置，避免与延长线或其他虚线含义混淆 |
| 立体图形与展开图 | 顶点、棱、面对应一致；可见棱实线、遮挡棱虚线并说明；高与斜高区分；展开图能折回目标立体，不遗漏或重复面；不因透视变形推断真实长度和角度 |
| 统计图 | 数据来源、分类、单位、刻度与图例完整；柱高、扇区和数值一致，不用装饰性面积制造错误比例 |

原图通常用深色实线，新增辅助线可用细虚线或少量红色，并加文字说明。线条仍须足够清晰可打印；虚线含义在同一图内保持明确。标注避开交点和线条，直角与等长记号只标确实成立的关系。

非按比例的几何关系图注明“示意图，不按比例”，但仍须保持拓扑和已声明的关系正确；这不能用来豁免坐标点、函数走势或统计数据错误。不能从像素外观代替证明。

## 测评

根据目标组合概念辨析、计算、应用、证明与作图，不要求每次全部出现。图形题先区分“已给图形”和“待学生构造”：笔记可展示的辅助线、分割方式、坐标点或展开结果，在学生卷中只有题干明确给定时才能出现。

### 学生作答区

数学解题区默认使用整块纯白空白，不画书写横线、虚线、点线或装饰边框，让学生自由安排竖式、分数、方程、推理和辅助图。文字说明题（如解释理由、描述路线）也遵循此默认；用户明确要求横线时再添加。

- 计算、应用、证明及文字说明题：按完整解答所需的宽度和高度留白，题号、题间距帮助区分作答区域，不用横线分割解题步骤。
- 选择、填空题：保留选项填写括号、答案括号或短横线；长表达式及带单位答案留足宽度，不额外添加解题横线。
- 作图题：按题目提供纯空白区、必要的方格纸、坐标系或已给图形。网格与坐标轴是作图工具，不因“无横线”删除；不默认把所有解题区铺成方格纸。

面积估算可参考公共规范的书写行高，但行数仅用于内部估算，不代表要画线。分式、竖式和图形须额外考虑纵向高度；去掉横线后仍须保留原定答题空间，不能把空白收缩成普通题间距。

在逐页提示词中用毫米明确空白区尺寸，例如：“第3题下方预留全栏宽、约45mm高的纯白作答区；不画横线、虚线、点线或边框；不得填入答案。第2题给定的方格图完整保留。”尺寸按实际解答调整，不把45mm设为统一值。交付前检查生图是否擅自补了横线、缩小了留白或删除了必要网格。

### 作图与内容核验

作图题提供足够空白或所需网格，保留已给点线，不预画答案。几何证明与多步应用题根据完整解答预留空间。要求用尺量长度、量角器测角或严格比例作图时，先核实最终 PDF 在实际尺寸下的精度；整页生图无法保证时改成明确给定数值的题型。用户明确要求实际测量且精度无法保证时说明限制，不悄悄替换题目或声称可精确测量。

交付前独立核验计算、解的范围、单位、选项唯一性与图示规格。尤其检查负号、分数线、根号范围、指数、下标、不等号，以及图上是否多出改变题意的条件。答案插图遵循答案排版参考，可程序绘制以保证准确。

## 答案详解与解题图

默认按“思路 → 分步求解 → 结论与检验”讲解，简单题可合并表达。写清为什么选用该公式、构造或方法，不能只有算式链而没有关键依据。证明区分题设与已证结论，避免循环论证；应用题解释数量关系及单位，方程解检查是否符合实际条件。

解法依赖图形时配准确的解题图：几何题展示必要辅助线并说明为什么这样作；函数题标出用于求解的点、交点或区间；面积题标出分割/补形；立体题说明高、截面或展开对应。作图题提供完成图及作图步骤。纯计算题若文字足够清楚，无需强行配图。

例如采用“过 A 作 BC 的垂线，垂足为 D”的解法时，图中必须实际画出 AD、标出 D 和成立的直角关系，正文再说明如何使用高 AD；不能只加一条未命名的虚线。解题图与原题的点名、条件保持一致，新增构造明确区分，必要时分图避免遮挡。优先程序绘制精确数学图，按答案排版参考嵌入对应解析。
