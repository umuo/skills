# 通用学科内容规则

所有学科先用本规则；有专项说明时叠加专项，没有时直接依此完成任务。保持教材的术语、知识边界和学段要求，不把其他学科的笔记模板硬套过来。

## 课堂笔记

根据知识的性质选择组织方式，不要求每页包含所有模块：

- 概念类：具体例子 → 含义与条件 → 例与非例 → 易混点。
- 方法类：问题或目标 → 操作/推理步骤 → 典型应用 → 检查方法。
- 过程类：事件、变化或实验的先后关系 → 原因与证据 → 结论；区分先后发生和因果关系。
- 阅读与材料类：材料信息 → 结构与关系 → 有依据的解释 → 迁移运用。

按学生已有知识搭建解释；小学优先具体情境，初高中可提高抽象程度，但均保留理解所需的中间步骤。自编例子与教材原文分开，拓展明确标记，不虚构教材结论。

## 图示选择与规格

先明确“学生通过图能看懂什么”，再决定是否配图。数量关系可用分组/对比图，过程可用顺序图，空间关系可用结构示意，分类可用层级图；纯文字已足够时不强行配图。地理、历史、物理等未设专项的学科，按教材实际需要选择地图、时间线、实验装置等，不自动改用数学或英语模板。

在底稿中为必要图示写明：教学目的、对象及数量、关系或顺序、标签与单位、比例要求、与正文的对应位置。需要图例、方向、时间或数据来源时写清楚；示意图注明“示意”，不把示意外观作为精确测量依据。原始材料未支持的关系不能仅靠画面推断。

## 测评与检查

按学习目标选择辨认、解释、应用、材料分析或实践设计等题型，不照搬其他学科题型。先验证题目可解、答案范围与评分点，再估算作答空间。附上作答必需的材料；缺少音频、数据或可读图示时替换题型，不能编造已有材料。

学生卷仅展示题设给定的信息；需要学生完成的连线、标注、图形、步骤和结论保持空白。笔记可以展示完整示范，答案按独立排版路线提供解析。

校对时除逐字核对，还检查图文关系、单位、方向、时间顺序和标签是否支持所述结论；颜色携带的信息须有文字或线型等替代，便于黑白打印。无法可靠核实的内容不作为已确认知识交付。
