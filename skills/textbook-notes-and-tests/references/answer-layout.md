# 答案与解析：程序排版

答案默认直接排版为可检索文字的 A4 PDF，不先生成整页图片。这里的“硬编码”指用代码确定性地排版已核验内容，不是把某一本教材的答案写死在技能里。内容、样式和必要插图分离，答案改动不影响已完成的学生卷。

## 输入与实现

复用 `content.md` 中的独立答案部分；复杂题目可另存结构化数据，包含题号、答案、解析、分值与插图路径。保留实际使用的排版源文件或脚本在本次输出目录，勿放入 skill 包。

优先使用当前可用的 PDF 排版工具。可用 ReportLab 的 `SimpleDocTemplate`、`Paragraph`、`Table`、`Image`、`PageBreak` 等实现自动换行与分页；也可用可靠的 HTML/CSS 打印方案。按当前环境加载必要的 PDF 技能与运行依赖，不预设系统 Python 含某个库。

- A4竖版，边距至少12mm，正文通常12—14pt，标题与题号清楚；答案不需要学生卷式大块作答留白。
- 中英文混排选择有中文字形的字体，验证字体可嵌入及最终渲染无缺字。将内容传给富文本组件时转义 `&`、`<`、`>` 等符号，防止题目被解释为标签。
- 使用流式排版，别为每行硬写固定坐标。短题答案与解析尽量同页；长解析可自然续页，保留题号。页脚显示页码，只有取得实际页数后才写“共N页”。
- 选择题提供题号对应表与必要易错说明；计算题保留关键步骤和单位；开放题提供合理答案范围、示例及评分要点。
- 公式用支持数学排版的工具或程序生成的矢量图呈现；不用整页生图代替正确公式排版。

## 何时配图

先判断没有图是否影响理解。词义、选项字母、简短语法解释和普通评分表不需要生图。

| 需求 | 处理 |
| --- | --- |
| 数值表、购物预算、评分表 | 程序表格 |
| 数轴、坐标、几何关系、简单流程 | 程序绘制，确保比例与标签准确 |
| 有助于理解的情境图、复杂具象示意 | 单独调用 imagegen 生成插图，再嵌入正文 |
| 已有且准确的相关图 | 复用，不重复生成 |

生图插图先保存 `prompts/answer-figure-001.md`，明确图的教学目的、必须准确的关系和标签，使用 `scientific-educational` 场景。只生成插图本身，不将整页答案、解析或评分标准放进提示词。图注、题号及长段解释由程序排版，避免嵌入图中。

逐图验证数量、关系、标注与答案是否一致；生成式示意图不能替代精确作图。图片按实际嵌入尺寸计算有效 DPI，不按整张A4计算。复用已有插图时保留来源记录。

## 校验与交付

先核对题号覆盖、答案与学生卷一致、各题分值及评分细项之和正确。范文须满足题干的长度和内容要求，避免按示例答案才能得分，避免同一错误重复扣分。

生成后重新打开 PDF，核对页数与A4尺寸；提取文字检查缺漏，渲染全部页面检查中文字体、公式、表格分页和插图清晰度。程序排版同样需要视觉校验，但校验渲染不是 imagegen 调用。发现文字错误直接修改源内容重新排版；仅插图错误才修正对应插图。

答案作为独立 PDF 交付。没有插图时不创建空的答案图片目录，也不交付整页校验截图。图像合并脚本 `images_to_pdf.py` 仅用于整页生图的笔记/学生卷，不用于这一路线。
