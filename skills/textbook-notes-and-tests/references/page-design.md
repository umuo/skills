# 分龄页面与打印规范

本文件负责学段风格、分页与打印；内容组织和图示的学科要求按 `SKILL.md` 路由读取。图文并茂指图能帮助理解，不设插图数量指标；初高中简约也不能省略必要的坐标图、几何图或实验示意。

## 课堂笔记

### 小学

使用端正、清晰、非连笔的手写体，正文目标约 16–18 pt，低年级优先 18 pt。白底、深色文字，以少量彩色插图帮助理解。插图必须解释知识：例如分组计数、分数分割图、情节顺序或具体生活情境；不能仅放无关卡通装饰。

按“这是什么 → 看一个具体例子 → 为什么/怎么做 → 容易错在哪里 → 用自己的话回想”推进。一页只承载少量紧密相关概念；一句话表达一个意思，先具体后抽象。低年级需要注音时只给难字或关键字加准确拼音，避免全页小字注音。概念不能为通俗而改成错误结论。例题展示能理解的分步过程，图和步骤在空间上对应。

### 初中与高中

端正手写体、简约结构，正文目标约 12–14 pt，复杂公式另留空间。以概念、适用条件、方法步骤、一个典型例子和易错点组织页面。重点可用少量红色字或浅色背景，但要同时通过框线、下划线或文字标签体现重要性，黑白打印仍可辨认。不用大面积卡通装饰。

分清定义、定理、经验方法和例子，保留公式成立条件、单位、符号说明与推理关键步骤。高中不能因追求简洁省去定义域、前提和特殊情况。

### 分页

先规划完整单元，再划分页面；避免每页重复简介却遗漏后半部分。一般让一个概念及其图示/例题留在同一页，内容过多时拆成“概念”“应用”连续页。笔记练习的答案放在单独位置并标清，不干扰先思考。

## 测评试卷

四种范围分别处理：

| 类型 | 出题原则 |
| --- | --- |
| 知识点专项 | 核心概念、基础运用、变式与易错辨析；只调用必要前置知识 |
| 单元测评 | 覆盖单元主要目标及其联系，避免被某个容易出题的小节占满 |
| 期中测评 | 依据确认的已学范围跨单元组合，不默认半本书 |
| 期末测评 | 覆盖确认的整册/累计范围，以基础掌握和综合应用为主 |

用户未指定难度时，以基础约 60%、常规应用约 30%、综合提升约 10% 的分值比例作为可调整起点，随学段和范围修正，不声称这是官方标准。不把超纲拓展当成必答题，不使用未提供音频的听力题。

试卷默认白底黑字，使用清晰常规字体即可，用户的手写体要求主要针对笔记。小学正文目标 14–16 pt，初高中 12–14 pt；字号是最终打印视觉目标，需渲染检查，不能只写在提示词里就视为满足。题号、分值、选项与图示标注清楚，首面留姓名、班级、日期，标明范围、建议时长和满分。

主观题的答题空间按预期解题步骤计算：小学行距约 9–10 mm，初高中约 7–9 mm。短答至少 2–3 行，多步计算/应用至少 4–6 行；证明、实验、作图、作文依据实际任务增加区域或专页。以上仅为起点，结合自己的解答检查学生能否写下。几何作图留空白方框，作文按要求留足格子/横线。

选择题只留选项填写处，填空题只留足以写实际答案的横线或括号，不必额外留解题过程区。长表达式和带单位答案仍需足够宽度。禁止在学生卷留白区填上示范步骤、答案、淡色答案水印或暗示性插图。

优先把题干、必要图示与答题区域放在同页。长题确需跨页时注明“接上页第 X 题”，提供必要上下文，不让学生反复翻页看条件。页数随答题空间增加，不能靠缩小字号满足预设页数。编排时先估计正文换行、选项、题间距和书写区总高度，再定页数。避免一页很空、下一页堆满选择题与对话；优先移动完整题组，不跨页拆开短对话。样页选择较密页，而不是只有标题和少量题目的首页。

答案默认程序排版为独立 PDF，详见 [answer-layout.md](answer-layout.md)。题号与学生卷一一对应。包含关键步骤、分值分配和开放题评分要点；检查分项总分与首页总分一致。用户只要学生卷时保留内部文字解答用于校对，不额外交付答案文件。

## 每页提示词模板

以下字段需替换为已审定的实际内容，不能把占位符送去生图：

```text
Use case: scientific-educational
产物：可直接打印的 A4 竖版[课堂笔记/学生试卷]，第[页码]页，共[总页数]页。
对象：[学段、年级、学科]；范围：[教材与单元/知识点]。
页面：纯白平面，无透视、桌面、纸张阴影或装饰边框；四边至少12mm安全区。
风格：[小学清晰手写图文/初高中简约手写/试卷清晰黑字]。
文字：正文打印目标[字号]pt，深色高对比；公式与图标准确；不得自行改写或添加文字。
布局：[每块的顺序、位置和空间；主观题空白区以mm与行数说明]。
正文（逐字呈现）：
[该页完整定稿，包含题号、分值、选项、公式、页码等]
图示：[对象、数量、几何关系、标签的准确规格；无图时明确无图]。
教学用途与图文对应：[图帮助解释哪一步；正文、符号与图中标注怎样对应]。
学科约束：[本页实际适用的条件、线型/刻度/读音等要求；区分题设已给信息与不可提前展示的解题信息]。
留白：[哪些区域保持纯空白/横线，不能填写解答]。
强调：[红字/浅底的具体重点；试卷通常无彩色强调]。
禁止：错别字、伪文字、漏项、重复题号、挤压文字、跨安全区、学生卷出现答案。
```

## 交付前检查

先核内容，再看美观。检查教材范围是否吻合、正文是否与审定稿一致、图示是否真正支持结论、答案是否可解且评分一致。查看最终 PDF 的全页效果和文字局部，按实际打印尺寸估算字体与书写区。红色重点在灰度下不能消失；公式和图示线条不能细到印不出。
