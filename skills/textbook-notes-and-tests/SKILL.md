# 教材课堂笔记与测评

将指定教材的指定范围转化为学生能理解、能阅读、能书写的打印资料。按产物选择生成方式，避免将纯文字答案也整页生图：

| 产物 | 默认方式 |
| --- | --- |
| 手写风课堂笔记、学生试卷 | imagegen 逐页生成，再按顺序装入 A4 PDF |
| 参考答案与解析 | 代码直接排版文字、表格和公式，输出独立 PDF |
| 答案中的必要插图 | 简单几何、坐标图、流程图优先程序绘制；需要情境画面或复杂示意时单独调用 imagegen，再嵌入答案 |

用户口中的 imggen 指 imagegen 生图能力。用户指定其他生成方式时优先遵从；默认答案程序排版无需另行确认。生图仅用在确有视觉收益的答案插图上，不为统一风格而生成整页答案。

## 1. 确定教材与任务

从对话提取学段、年级、学科、出版社/版本、册次（上/下册或必修/选择性必修及册号）；存在新版修订、学制或英语起点差异时也需核实。不重复询问已有信息，不默认人教版。缺失信息影响教材匹配时，集中询问必要项。

明确产物是课堂笔记、试卷还是两者。教材到手后核对目录，再定位用户要求的单元、课时或知识点；范围不明时给出实际目录中的候选项并询问。期中考查范围需根据已学进度确定，不能简单取教材前一半；期末确认整册还是指定累计范围。

题量、难度、时长、总分和纸张颜色偏好可依据年级与范围提出合理默认值并说明，无需为每个可选项停下来。用户指定页数时评估是否容得下内容与书写空间；冲突时说明并请求取舍。

## 2. 获取并核对教材

先在用户提供的位置、当前任务资料和已知教材下载目录查找可复用 PDF；没有匹配教材时再使用 `smartedu-textbook-download` 获取。执行细节见 [references/textbook-source.md](references/textbook-source.md)，首次下载前必读。

下载完成不能只看文件名：打开 PDF，核对封面、版本、册次和目录。记录教材路径、标题、版次/年份（可识别时）、目标单元，以及 PDF 页序号与印刷页码的对应关系。扫描教材需渲染相关页面阅读，OCR 仅作辅助；公式、图示、标注和表格须看原页。

教材未获取、版本不匹配或目标页面读不清时说明实际问题，请用户补教材/页面或明确调整范围，不把通用知识冒充教材内容。

## 3. 分析与编写内容底稿

### 按学科渐进加载

确认学科后，先读 [references/subjects/general.md](references/subjects/general.md) 作为通用内容规则，再仅加载下表中匹配的专项说明。专项说明补充通用规则，学段风格与打印要求仍由页面设计参考控制；不要一次读取所有学科文件。

| 教材学科（含常见称呼） | 专项说明 |
| --- | --- |
| 语文、Chinese | [references/subjects/chinese.md](references/subjects/chinese.md) |
| 数学、Math、Mathematics | [references/subjects/math.md](references/subjects/math.md) |
| 英语、English | [references/subjects/english.md](references/subjects/english.md) |
| 其他学科，或对应专项文件不存在/不可读 | 只用通用规则，结合实际教材确定内容结构、图示和题型 |

按教材的实际学科判断，不因内容含数字就套用数学规则，也不把所有外语视为英语。学科明确但尚无专项说明时直接继续，不要求用户改选学科，不为本次生成自动创建新学科文件；学科本身不明确且影响教材匹配时才询问。跨学科任务以主学科为主，仅对实际涉及的部分加载相关专项；其余部分回退通用规则。在 `source-map.md` 记录实际学科、学段、所用专项或通用回退。

### 内容底稿

先形成 `source-map.md`：每个知识点对应的教材页码、核心概念、关键条件、前置知识、典型例子、易错点和适龄拓展。区分教材内容、自己编写的例题和拓展；拓展标为“选学/拓展”，默认不纳入测评分数。

再形成 `content.md` 与逐页计划。例题和试题先独立求解核验，检查条件是否充分、单位与符号是否正确、选项是否唯一（多选题明确标注）。语文等开放题提供合理答案范围与评分要点，不强行声称只有唯一表述。

- **课堂笔记**：读 [references/page-design.md](references/page-design.md) 的笔记部分，按理解顺序组织内容。可以用多页讲清一个单元，不以缩字挤满一页。
- **试卷**：读同一参考的测评部分。先编制知识点—题号—难度—分值映射，再编题、求解、核对总分与预计耗时。保留独立答案底稿用于校对；除非用户另有要求，同时生成单独的参考答案与解析 PDF，不能混入学生试卷。

## 4. 选择排版路线并控制生图成本

答案先读 [references/answer-layout.md](references/answer-layout.md)，直接从已核验的答案底稿程序排版；更正答案时只修改底稿并重新排版，不触发学生卷生图。用户仅要答案时跳过整页生图流程。

答案默认逐题提供适龄详解，包含结论、解题依据和必要的推理/计算过程，不能仅交付选项表或最终结果。数学等依赖图形理解的题须配解题图，并解释图中构造与步骤的关系；详细程度与题目复杂度匹配。仅在用户明确要求简答版时缩减解析。

为本次任务列出笔记/学生卷生图页数、答案程序排版及必要插图数量，说明默认安排即可，不增加例行审批。页数由题量和书写空间决定，不为省一次调用压缩可读性。先生成一张有代表性的较密样页，验证文字、留白、实际像素和排版风格后，再生成其余页面；不要在样页未通过时整批生成。

### 笔记与学生卷生图

查找并完整读取当前环境的 `imagegen` skill，按其流程调用真实生图工具；默认使用内置能力，每一页单独生成。环境缺失该能力时说明笔记/学生卷生图受阻，不宣称已生图；可继续完成底稿及程序排版答案。API/CLI 替代方式遵从 imagegen 的授权要求。

每页先保存提示词到 `prompts/<类型>-001.md` 等文件，写清：学段、学科、页号、A4 竖版、白底、打印字号目标、版面分区、逐字正文、准确图示及标签、答题空白尺寸、不可出现的内容。将本页适用的学科教学结构、图示规格与检查重点具体化到提示词，不把整份学科说明当成正文送去生图。使用 `scientific-educational` 场景。提示词模板见页面设计参考。

统一同一份资料的笔迹、标题层级、色彩和页码位置。初次生成后可将合格页作为后续页面的风格参考，但每页正文必须独立明确。用户要两种产物时，笔记与试卷分别编号，不在一张图片里拼多张纸。

生图目标为接近 A4 比例的高清竖图；打印理想目标约 2480×3508 像素（整张 A4 约 300 DPI），实际能力以工具为准，不把像素需求伪装成工具支持的参数。内容四边预留至少 12 mm 安全区。禁用拍照透视、纸张阴影、桌面背景、折痕、装订装饰和大面积底纹。

工具返回后保存路径与必要元数据即可，不将包含 base64 的整个结果作为文本输出。通过工具的原生图像显示或图片查看能力校对，避免重复传输同一图片。已合格页面保留复用，题目修改只重做受影响页面。

## 5. 图像校对与修正

逐页查看真实输出，对照底稿逐项核对文字、题号、选项、公式、分数上下标、图表标签与页码。检查重点标色未遮挡文字，学生卷没有答案提示，解题区足够。中文、公式和密集文字可能被生图模型改错；不能只凭画面美观判为合格。

同时执行已加载学科说明中的专项检查；回退通用规则时按实际图示与题型检查。数学的点线面关系、坐标刻度、立体遮挡等须对照底稿逐项确认，不能仅核对图中文字。

发现内容错误，通过 imagegen 编辑或重新生成该页；重查整页，防止修正一处破坏另一处。针对同一问题一次修正仍失败时，先减少内容或调整布局再尝试，不原样反复抽图。纯装饰差异不值得重生。仍无法达到正确可读的程度时，交代未解决的问题并标记为草稿，不能把有误试卷当成可打印成品。对整页生图的笔记/学生卷，Python 只做装页、方向/透明底归一与校验，不用代码覆写题目绕过图像修正。此限制不适用于默认程序排版的答案；答案中的生图插图仍须逐图核对。

## 6. 合并 A4 PDF 与交付

将最终图片保存到本次输出目录，按 `notes-001.png`、`test-001.png` 分类；答案插图使用 `answer-figure-001.png`，不要求生成答案整页图片。记录源教材、底稿、提示词、最终图片及输出文件的路径；不要把下载教材或生成资料放入 skill 包本身。

整页生图产物使用 [scripts/images_to_pdf.py](scripts/images_to_pdf.py)，依赖 Python 3.10+、Pillow、reportlab。在可用环境复用已有依赖，否则在当前项目虚拟环境安装 `pillow reportlab`。

在输出目录建立清单，路径相对于清单文件，数组顺序即页序：

```json
{"pages": ["images/notes-001.png", "images/notes-002.png"]}
```

```bash
python3 /path/to/textbook-notes-and-tests/scripts/images_to_pdf.py \
  --manifest notes-pages.json --output notes.pdf
```

每张图装入一张 210×297 mm A4 页面，等比缩放、居中、不裁切，不拉伸。图片内已经有安全区，默认不叠加 PDF 外边距；若图片缺少安全区，可用 `--margin-mm 12`，随后检查缩小后的文字。样页阶段即按实际像素计算有效 DPI：min(像素宽÷实际印刷宽英寸, 像素高÷实际印刷高英寸)，合并脚本会再次报告。低于 200 时先检查最密文字局部；优先使用工具真实支持的高分辨率能力，否则降低单页密度和增大字体。降低密度不会提高 DPI，只改善可读性。不因提示词写了“300 DPI”就认定高清，不为相同分辨率盲目重试，也不靠插值放大或更改 DPI 标签宣称提高画质。若仍不可读，标为草稿并说明；可读但低分辨率时，交付应说明限制并建议先试印。

笔记、学生卷分别用独立图片清单合并；答案走程序排版路线，独立输出 PDF，无需经过图片清单。脚本只保证装页，不证明内容正确。使用可用 PDF 工具重新打开，确认页数与 A4 尺寸，再渲染最终 PDF 逐页检查裁边、顺序、文字大小及答题空间，必要时查看灰度预览。按 100% 实际尺寸评估阅读与书写，不仅看放大的屏幕效果。

交付 PDF 链接与原始页面图片目录，简述教材版本、范围、页数、试卷分值/时长（适用时）和实际校验结果。说明按 A4、实际尺寸打印；有待核对项必须显式列出，不宣称已完成真实纸质打印测试。
